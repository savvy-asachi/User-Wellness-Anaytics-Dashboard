# User-Wellness-Anaytics-Dashboard
Interative Power BI dashboard for analysing Fitbit user wellness data using python(pandas),Excel and Power BI with feature enginnering and busines inights


## Project Overview
This project is an interactive Power BI dashboard developed to analyse Fitbit user wellness and activity data. The dashboard transforms raw fitness data into meaningful business insights through data cleaning, feature engineering, and interactive visualisations.

## Business Problem
Analysing raw fitness data can be difficult and time-consuming. This dashboard provides stakeholders with an easy-to-understand view of user activity, wellness, and engagement, enabling faster and more informed decision-making.

## Project Objective
- Analyse Fitbit user activity data.
- Build meaningful wellness metrics.
- Create an interactive dashboard for analysing user behaviour.
- Present insights through Power BI visualisations.

## Tools & Technologies
- Python (Pandas)
- Excel
- Power BI
- Power Query

## Feature Engineering
Created the following calculated fields:
- Wellness Score
- Activity Level
- Risk Level
- User Segment

## Dashboard Features
- KPI Cards
- Interactive Filters (Slicers)
- Scatter Plot (Steps vs Calories)
- Activity Level Distribution
- Top 5 Users by Wellness Score
- Wellness Score by User Segment

## Business Value
The dashboard helps stakeholders:
- Monitor user wellness and activity trends.
- Compare user groups.
- Identify highly active and lower activity users.
- Support data-driven wellness initiatives.

## Future Improvements
- Time-series trend analysis
- Additional health metrics
- Predictive analytics
- Larger datasets for deeper insights
